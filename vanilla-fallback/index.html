How the modules work together

  1. Memory – each admitted task needs a partition before it can run.
  2. Producer–Consumer – registrations and lab/imaging results are produced into a bounded buffer; processing tasks consume them.
  3. Banker's – before a task takes imaging equipment, printers or DB connections, the request is checked for safety.
  4. CPU scheduling – admitted, safe tasks are scheduled by priority so emergencies run first.
